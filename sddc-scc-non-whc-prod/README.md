# SCC-NON-WHC-PROD SDDC

 Creation of compute and networking infrastructure in VMC for the SCC-NON-WHC-PROD SDDC [Soldef](https://conf.willhillatlas.com/display/ARCH/VMC+on+AWS+Solution+Definition)

## SDDC

 Creates and manages SDDC and compute clusters.

## NSX

 Creates and manages all networking related infrastructure and rules.
